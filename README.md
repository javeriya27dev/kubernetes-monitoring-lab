# Kubernetes Self-Healing & Monitoring Lab
This project demonstrates a containerized Node.js application deployed on a local Kubernetes cluster (Minikube).

## Features
- *Containerization*: App packaged using Docker.
- *Orchestration*: Managed via Kubernetes Deployment and Service manifests.
- *Observability*: Monitored using the Kubernetes Dashboard.
- *Self-Healing*: Configured with automated pod management for high availability.

## Tools Used
- Node.js / Express
- Docker
- Kubernetes (Minikube)
- PowerShell# kubernetes-monitoring-lab
